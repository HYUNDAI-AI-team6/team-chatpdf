## 💻 실행 방법

### 1. 저장소 다운로드

```bash
git clone <저장소_URL>
cd <프로젝트_폴더명>
```

### 2. 가상환경 생성 및 활성화

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
source .venv/bin/activate
```

### 3. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 4. API 키 설정

프로젝트에서 사용하는 API 키를 환경변수로 설정합니다.
아래는 OpenAI API를 사용하는 경우의 예시입니다.

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="본인의_API_키"
```

macOS / Linux:

```bash
export OPENAI_API_KEY="본인의_API_키"
```

Hugging Face Spaces에서는 **Settings → Variables and secrets**에
프로젝트에서 사용하는 이름으로 API 키를 등록합니다.

### 5. 앱 실행

```bash
python app.py
```

실행 후 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 📖 사용 방법

1. 상담할 가전제품의 매뉴얼 PDF를 업로드합니다.
2. 문서 처리가 완료되었는지 확인합니다.
3. 질문을 입력하거나 자주 묻는 질문을 선택합니다.
4. 답변을 확인하고 필요한 경우 후속 질문을 이어갑니다.
5. 필요한 대화는 저장하고, 새로 시작하려면 대화를 지웁니다.
